STM32 RS485 总线调试实战

STM32 RS485 Modbus Embedded

硬件设计要点

  • 差分信号 120Ω 终端电阻
  • 收发自动切换电路 (RE/DE 控制)
  • 共模电压范围 ±7V
  • 隔离保护 (光耦 + DC-DC)

Modbus 协议

主机从机一问一答。功能码 0x03 读保持寄存器，0x06 写单寄存器。

uint8_t modbus_crc(uint8_t *buf, int len) {
    uint16_t crc = 0xFFFF;
    for (int i = 0; i < len; i++) {
        crc ^= buf[i];
        for (int j = 0; j < 8; j++) {
            if (crc & 1) crc = (crc >> 1) ^ 0xA001;
            else crc >>= 1;
        }
    }
    return crc;
}

常见坑

  • 收发切换时序不对 → 字节丢失
  • 终端电阻错配 → 信号反射
  • 波特率不匹配 → 数据乱码
