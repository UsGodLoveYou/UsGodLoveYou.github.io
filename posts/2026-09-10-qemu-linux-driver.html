QEMU 模拟 i.MX6ULL 跑 Linux 6.1 — 字符设备驱动实战

QEMU Linux Kernel Driver i.MX6ULL

环境搭建

用 QEMU 模拟 i.MX6ULL Cortex-A7 处理器，编译 Linux 6.1 内核 + busybox + 自定义字符设备驱动。

编译内核

make imx_v6_v7_defconfig
make -j$(nproc) zImage dtbs LOADADDR=0x80008000

驱动代码

static int mydev_open(struct inode *inode, struct file *file) {
    pr_info("device opened\n");
    return 0;
}

static ssize_t mydev_read(struct file *file, char __user *buf, size_t count, loff_t *ppos) {
    char msg[] = "Hello from kernel!\n";
    copy_to_user(buf, msg, sizeof(msg));
    return sizeof(msg);
}

static struct file_operations fops = {
    .open = mydev_open,
    .read = mydev_read,
};

module_init(mydev_init);

加载模块

insmod mydev.ko
cat /dev/mydev0
# 输出: Hello from kernel!
